# Fragmento — statická šablona na frgmt.to/fragmento-sablona
#
# NÁVRH ZMĚNY, NEAPLIKOVAT SÁM. `/home/ubuntu/little-buddy/Caddyfile` je
# živá edge konfigurace pro všech pět aplikací a podle handoveru patří
# mezi věci, kde „máš práva zápisu, ale používat je nemáš“.
#
# ── Co si tímhle blokem NEPŘEJEME ─────────────────────────────────────
#   * nezasahovat do APP_ROUTES v platform-auth
#   * nezakládat oprávnění ani novou aplikaci v /admin
#   * nesahat na směrování ostatních aplikací
# Šablona je jen složka souborů. Kdo je přihlášený a zná adresu, uvidí ji.
#
# ── Část, kterou jsem si jistý: obsluha souborů ───────────────────────

handle_path /fragmento-sablona/* {
    root * /home/ubuntu/fragmento-sablona
    encode zstd gzip
    file_server

    # Náhled nepatří do vyhledávačů (a za přihlášením se tam stejně
    # nedostanou). Hlavička je spolehlivější než meta ve 22 souborech.
    header X-Robots-Tag "noindex, nofollow"

    # Otisk verze je v adrese (?v=…), takže se smí cachovat natvrdo.
    @assets path /assets/*
    header @assets Cache-Control "public, max-age=31536000, immutable"

    # Průvodní soubory balíčku nejsou pro návštěvníka.
    @interni path /_*
    respond @interni 404

    handle_errors {
        rewrite * /404.html
        file_server
    }
}

# ── Část, kterou si jistý NEJSEM: brána ───────────────────────────────
#
# Zadání zní „dostane se tam každý, kdo je zalogován“. To znamená, že
# blok musí projít stejnou branou jako ostatní aplikace — jenže **jak je
# ta brána v tomhle Caddyfile zapsaná, jsem neviděl**. Popisuje to
# ARCHITECTURE.md, sekce 3, která je na serveru.
#
# Nevymýšlím ji, protože je tam popsaná past s `route { }`, která už
# jednou tiše rozbila předávání identity aplikacím. Špatně umístěný
# `handle` uvnitř nebo vně `route` mění pořadí vyhodnocení.
#
# Co je potřeba udělat: **zkopírovat tutéž direktivu, jakou má třeba
# /collections**, a jen vyměnit cestu. Nic jiného.
#
# Kdyby brána nešla použít bez zápisu do APP_ROUTES, je to v rozporu se
# zadáním („ať to nikam nevstupuje“) a musí se to probrat — ne obejít.
